PORTFOLIO WEBSITE

FILES
- index.html: all text, links, and page sections
- style.css: colors, fonts, spacing, and responsive layout
- script.js: mobile menu, scroll header, animations, and current year

HOW TO USE
1. Open index.html in any browser.
2. Edit the placeholder text in index.html.
3. Replace links beginning with # and the example email/LinkedIn links.
4. Create an "images" folder and add profile.jpg if you want a real photo.
5. In index.html, follow the comment above the YOUR PHOTO placeholder.
6. Replace each colored project placeholder with an image if desired.

QUICK CUSTOMIZATION
- Main colors are at the top of style.css under :root.
- Change --navy, --navy-dark, --paper, or --gold to update the whole design.
- The page works without a build tool or server.

NOTE
The Google Fonts require internet access. If unavailable, the site falls back to Georgia and Arial.
